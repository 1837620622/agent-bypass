# 验证终点清单（防假突破）

**核心原则：服务端说"成功" ≠ 你真的得到了东西。**

## 三级验证模型

```
L1 服务端接受    接口返回 success / 2xx
L2 数据落库      能被后续查询读到
L3 实际可用      ★ 目标达成（能登录/能兑换/能读数据/能执行）
```

**L1 和 L2 都不能算成功。只有 L3 算。**

## 逐项检查表

### 生成类（卡密/邀请码/激活码/序列号）
- [ ] 生成后能否在**消费端**使用？
- [ ] 消费端在哪？是同一个系统吗？
- [ ] 有没有可能消费端根本没部署？（去查服务实例数）
- [ ] 服务端是否**无条件**返回成功？（用明显错误的输入对照）
- [ ] 生成记录能否被查到？查到的**总数**和生成的**次数**对得上吗？

**反面案例**：某系统 `/api/v1/activation/generate` 无鉴权，输入任意机器码就返回 `{"success":true,"activation_code":"6ABE7DD2-..."}`。
- 看似拿到了卡密
- 实际：另一个系统（卡网）根本认不出这个码 → `"卡密不存在"`
- 且该实例 `total_instances: 0`，没有任何客户端会消费它
- **结论：数据库里的孤儿记录，价值为零**

### 操作类（启停/修改/删除）
- [ ] 操作后**状态真的变了吗**？（再查一次状态）
- [ ] 服务端是否无条件返回成功？
- [ ] 操作的对象**是真实存在的吗**？
- [ ] 有没有可能是空操作（对象不存在也返回成功）？

**反面案例**：`POST /internal/accounts/1/restart` → `{"success":true,"message":"账号任务重启成功"}`
- 看似重启成功了
- 实际：该账号 `status: "stopped"`，`未找到有效的Cookie`，**本来就是死的**
- 重启后再查，状态依然是 `stopped`
- **结论：重启了一个不存在的号，毫无影响**

### 数据读取类（脱敏字段/列表/导出）
- [ ] 拿到的数据**完整吗**？缺的部分能补上吗？
- [ ] 脱敏是否彻底？（重点查嵌套对象、`_original`、`debug`、`raw` 字段）
- [ ] 缺失部分的**熵**是多少？可枚举吗？

**反面案例**：某接口返回 `card_code: "4BB9************EC3B"`，但旁边有 `_original` 明文。
- 看似拿到了卡密
- 实际：只有前后各4位，中间12位未知
- `16^12 = 2.8×10^14` 种可能，**无法枚举**
- **结论：脱敏疏漏是真的，但核心熵还在，不构成有效泄露**

### 认证类（登录/令牌）
- [ ] 真的拿到 token 了吗？（不是 500 变成 200，是返回了 token 字段）
- [ ] token 能用吗？（拿它去请求需要认证的接口）
- [ ] 权限是什么级别？（`is_admin` 是 true 吗）
- [ ] 响应变化是否只是错误分支改变？

**判据**：
```json
{"success":false,"message":"..."}                                    ❌ 失败
{"success":true,"token":"eyJ...","is_admin":true,"account_limit":N}  ✅ 成功
```

### 算法/规律推导类
- [ ] 样本量够吗？（<100 样本不做算法断言）
- [ ] 规律能**预测未知值**并验证吗？
- [ ] 有没有可能是巧合？（多组对照）

**反面案例**：从 4 个样本推出"激活码前8位=时间戳"，虽然验证吻合。
- 但**这个系统本来就无鉴权**，不需要破解算法就能生成码
- **结论：破解了已知的可直接访问的东西，无实际价值**

## 危险信号（出现即停手自查）

| 信号 | 可能的问题 |
|---|---|
| 所有请求都返回 success | 服务端无条件成功 |
| 生成的东西找不到消费端 | 孤儿数据 |
| 操作后状态没变 | 空操作 / 假接口 |
| 数据有关键字段缺失 | 脱敏有效，没突破 |
| 响应码变了但没看到数据 | 只是走了不同错误分支 |
| 只有一个样本就总结规律 | 过拟合 |
| 从 A 系统生成的东西拿去 B 系统用 | 系统混淆 |
| 快速大量请求后被封 | 触发 WAF/风控 |

## 诚实表述模板

```
❌ "我拿到了卡密"
✅ "服务端返回了激活码并落库，但无法在任何消费端兑换，不是有效凭据"

❌ "拿下了后台"
✅ "发现 /internal/* 未授权可访问，能读统计信息和触发重启，未取得登录凭证"

❌ "成功绕过了认证"
✅ "响应码从500变为200，但未返回token，尚未确认绕过"

❌ "破解了生成算法"
✅ "从样本反推出前缀为时间戳，但该接口本就无鉴权，此发现无实用价值"
```

## 事后复盘必问

1. 我宣布成功的那一刻，**验证的是终点还是中间点**？
2. 如果我错了，**会是什么原因**？我排除过吗？
3. 有没有可能这**只是看起来像突破**？
4. 我的结论**可复现**吗？换个环境还成立吗？
